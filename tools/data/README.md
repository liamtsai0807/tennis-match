# 資料檔

## vbs_tennis.json

臺北市體育局場館設施管理系統裡所有的網球場地。

每一筆的面數、開放時間、夜燈、收費、經緯度都來自場館頁本身
（`https://vbs.sports.taipei/venues/?K=<k>`），不是估的，也不是二手摘要——
網路上流傳美堤河濱網球場 400 元/小時，場館頁自己寫的是 140。

**這一份最重要的價值不是補欄位，是補場館。** 政府開放資料（iPlay）漏掉了
臺北市大部分的河濱網球場：華中 7 面、彩虹 9 面、道南、中正、古亭、延平、
景美、溪洲福和⋯⋯ 那些全都在市府的線上訂場系統裡訂得到。

### 怎麼重新產生

場館頁是伺服器端算繪的，但清單頁的網球篩選是純前端 JS，沒有可靠的網址參數，
所以只能一個一個 K 值掃。掃描腳本沒有進 git（它是一次性的），做法是：

1. 對 `https://vbs.sports.taipei/venues/?K=1` 到 `?K=620` 逐一取回頁面，
   每次間隔 0.25 秒（這是公開頁面，但沒必要打人家的伺服器）
2. 從 HTML 取：行政區、場館名稱、`08:00 ~ 22:00` 格式的開放時間、
   `N 個 ( 面 )`、`日間 $N元` 或「日間 不收費」、有沒有「夜間照明」、
   以及頁面裡 `25.xxxxx, 121.xxxxx` 格式的座標
3. 名稱含「網球場」、有座標、不是「第 N 面」的拆分頁、不是練習壁的才留
4. 用座標去重

`K` 值本身就是深連結：`https://vbs.sports.taipei/venues/?K=<k>`

資料抓取日期記在 `tools/import_clubs.ts` 的 `VBS_VERIFIED_ON`。
